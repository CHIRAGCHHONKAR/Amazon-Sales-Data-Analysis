## Project Title: Amazon Sales Performance Dashboard

## Project Overview:
This project involves a comprehensive analysis of Amazon sales data to identify business-critical insights regarding order volume and consumer behavior.

## Key Business Insights:
* Total Sales & Volume: Successfully tracked 40K total orders resulting in 60M in total sales.
* Order Trends: Identified a significant decrease in order counts from June leading into July.
* Product Performance: Top products include Wireless Mice and Bluetooth Headphones, with over 8K units sold for the top items.
* Payment Methods: Customers are split almost equally between Cash on Delivery (50.1%) and Prepaid methods (49.9%).

## Tech Stack:
* Power BI Desktop (Data Visualization)
* Excel (Data Source)
